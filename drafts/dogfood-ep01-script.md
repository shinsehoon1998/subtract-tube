# 빼기연구소 EP01 — "영상 한 편에 며칠? 클로드 코드로 기획~대본을 하루로 줄였습니다"

> 생성 스킬: `yt-script` (비즈니스PT 페이스리스 롱폼). 페이스리스 = 나레이션 + 화면큐.
> 핵심 문제 1문장(고정·결의 기준점): **"영상 한 편 만들려면 기획부터 대본까지 며칠이 걸려서, 꾸준히 못 올린다."**
> 채널/타겟: 빼기연구소 — 불필요한 업무를 AI로 자동화하고 싶은 직장인·크리에이터(25~40세).
> 분량 목표: 나레이션 합계 3000자 ±5%.

---

## 도입부 디벨롭 노트 (검증된 도입부 → 1:1 단어 치환)

벤치마크 2개는 제목만 확보(스크립트 미확보). 따라서 제목 + 일반지식으로 도입부를 **재구성**해 1:1 치환을 시연한다.
**[데모: 실제 운영 시 뷰트랩에서 추출한 벤치마크 원문 스크립트를 여기에 삽입]**

- 벤치마크 ①: "클로드 코드 쓰고 유튜브영상 제작하는 방식이 완전히 달라졌습니다"
- 벤치마크 ②: "(오픈소스 제공) 클로드 코드로 긴 영상을 100% 자동으로 만들어보았습니다｜Claude Code"

**차용 단계: 1단계(같은 주제 — 클로드 코드 × 영상 제작 자동화).**

| 구분 | 문장 |
|---|---|
| **차용 원문(재구성)** | "클로드 코드를 쓰고 나서, 제 유튜브 영상 만드는 방식이 완전히 달라졌습니다. 예전엔 한 편에 며칠이 걸렸거든요." `[데모: 실제 운영 시 뷰트랩 스크립트 삽입]` |
| **1:1 치환 결과(우리 주제)** | "클로드 코드를 쓰고 나서, 영상 한 편에 며칠씩 잡아먹던 기획과 대본이 하루로 줄었습니다. 골격은 그대로, 명사·동사만 우리 문제로 교체." |

치환 규칙 적용: 문장 골격("OO를 쓰고 나서 ~ 방식이 완전히 달라졌습니다 / 예전엔 며칠이 걸렸다")은 유지하고, "영상 만드는 방식" → "기획·대본 며칠 → 하루"로 명사·동사만 갈아끼움.

**후킹 유형: #11 갈아타기 간증형 (주) + #9 직접 같이 해보기형 (보조).**
**후킹 공식 적용:** 사전신호("영상 꾸준히 올리는 게 핵심인 건 다 안다") → 예측오류("그런데 정작 한 편 만드는 데 며칠이 걸려 못 올린다") → 인지적 명료성("문제는 의지가 아니라 '기획~대본' 구간이었고, 그 구간을 클로드 코드가 통째로 가져갔다").
**도입부 3요소:** ① 문제제기(며칠 걸려 못 올림) ② 사례(주말 통째로 날린 경험) ③ 유인(무료 스킬팩 + 따라 하면 하루로).

## 세그먼트 1
[나레이션]
클로드 코드를 쓰고 나서, 영상 한 편에 며칠씩 잡아먹던 기획과 대본이 하루로 줄었습니다. 솔직히 말하면 저는 의지가 약한 사람이라고 자책했었어요. 채널 키우려면 꾸준히 올려야 한다는 거, 모르는 사람 없잖아요. 그런데 막상 한 편 만들려고 앉으면 주제 정하고, 자료 찾고, 대본 쓰다가 주말이 통째로 날아갑니다. 그러다 두세 편 올리고 지쳐서 멈추기를 반복했죠.

[화면/비주얼 큐]
- 자막 키워드: 며칠 → 하루 / 기획·대본 / 주말이 통째로
- B-roll: 달력에 빨간 X 표시가 쌓이는 모션, 노트북 앞에서 한숨 쉬는 실루엣
- 강조: "며칠 → 하루" 화살표 전환 애니메이션, "하루" 숫자 확대

## 세그먼트 2

[화면/비주얼 큐]
- 자막 키워드: 병목은 '앞단' / 기획~대본 / 빈 화면을 노려보는 시간
- B-roll: 제작 파이프라인 다이어그램(기획→대본→촬영→편집), '기획~대본' 구간만 빨갛게 깜빡임
- 강조: 빨간 구간에 "여기서 며칠" 라벨 팝업

## 세그먼트 3
[나레이션]
오늘 알려드릴 방법은요, 현재 국내외에서 수만 뷰 이상 나온 클로드 코드 활용 콘텐츠 중에서도, 영상 제작을 실제로 자동화해본 사람들의 실전 노하우만 추린 겁니다. 해당 내용은 "클로드 코드 쓰고 유튜브 영상 제작 방식이 완전히 달라졌습니다" 영상과, "오픈소스 제공, 클로드 코드로 긴 영상을 100퍼센트 자동으로 만들어봤습니다" 두 채널의 콘텐츠를 참고했습니다. 핵심은 한 가지입니다. 영상 제작을 한 번에 다 하는 게 아니라, 단계별 스킬로 쪼개서 클로드 코드에 맡기는 겁니다. 주제 잡기, 도입부 만들기, 본문 쓰기, 마무리하기를 각각 작은 작업으로 나누면, 클로드 코드가 한 단계씩 정확하게 처리합니다. 한 번에 완벽한 결과를 기대하면 실망하지만, 쪼개면 매 단계가 안정적으로 나옵니다.

[화면/비주얼 큐]
- 자막 키워드: 수만 뷰 검증 / 두 채널 참고 / 단계별 스킬로 쪼갠다
- B-roll: 참고한 두 벤치마크 영상 썸네일 캡처(출처 자막 표기) [데모: 실제 운영 시 원본 캡처 삽입]
- 강조: "쪼개서 맡긴다" 하이라이트

## 세그먼트 4
[나레이션]
조금 더 풀어볼게요. 사람들이 대본 쓰기를 어려워하는 진짜 이유는, 빈 화면에서 0을 1로 만들려고 하기 때문입니다. 그런데 잘 되는 채널들은 0에서 시작하지 않습니다. 이미 성과가 검증된 영상의 구조를 가져와서, 자기 주제로 단어만 바꿔 끼웁니다. 부동산에서 잘 먹힌 도입부 골격을 운동 영상에 그대로 옮기는 식이죠. 클로드 코드는 이 작업을 기가 막히게 잘합니다. 벤치마크 영상 두 개만 주면, 검증된 도입부를 우리 주제로 1대 1 치환해서 첫 문장부터 뽑아줍니다.

[화면/비주얼 큐]
- 자막 키워드: 0→1이 아니라 / 검증된 구조 차용 / 1:1 치환
- B-roll: "부동산 도입부 → 운동 도입부" 단어가 슬롯머신처럼 갈아끼워지는 모션
- 강조: 바뀌는 명사·동사만 색상 강조

## 세그먼트 5
[나레이션]
그럼 실제로 어떻게 돌아가는지 같이 보시죠. 먼저 채널 주제와 이번 영상의 핵심 문제 한 문장, 그리고 벤치마크 영상 두 개를 클로드 코드에 입력합니다. 그러면 첫 단계로 도입부를 디벨롭합니다. 검증된 도입부를 가져와 문제제기, 사례, 유인 세 요소가 다 들어가도록 우리 주제로 치환해주죠. 다음 단계에서 본문을 6단계 구성으로 채우고, 출처 문장과 마무리, 고정댓글까지 한 번에 만들어 냅니다. 제가 며칠 걸려 하던 걸, 이 흐름이 몇 분 만에 초안으로 끝냅니다.

- B-roll: 터미널에 스킬 실행 → 세그먼트가 자동으로 출력되는 화면 녹화 [데모: 실제 운영 시 시연 녹화 삽입]
- 강조: 출력되는 "[나레이션]/[화면큐]" 블록 강조 박스

- B-roll: 업로드 그래프가 우상향으로 쌓이는 모션, 구독자 카운터 증가 애니메이션

## 세그먼트 10
[나레이션]
