# yt-script — 비즈니스PT 페이스리스 롱폼 원고 생성기

> 호출자: 빼기연구소 크리에이터(또는 subtract-tube 파이프라인). 다운스트림 소비자: `yt-voiceover`(TTS), `yt-render`(Remotion 조립).
> 목적: 채널 프로파일(내 말투·구독자 니즈) 위에서, 주제(해외 현지화) + yt-structure 요소별 구조를 **차용·치환**해 페이스리스 TTS용 한국어 롱폼 원고를 만든다. 신규 창작이 아니라 "성과 검증된 남의 구조 → 내 주제로 1:1 치환, 단 최종 보이스는 내 채널 프로파일".
> 내부 소스 오브 트루스: `knowledge/biz-pt-longform-blueprint.md` (§0 KPI 게이트, §4 원고 방법론), `knowledge/practice-sheet-digest.md` (STAGE 4). 이 스킬은 그 방법론을 자체 포함(self-contained)한다.
> 크리에이터 확정 지시: **"페이스리스 간다"** — 얼굴 노출 없이 나레이션+화면큐로만 구성. 출력은 반드시 세그먼트 분할 형태.

---

## When to Activate

다음 중 하나면 이 스킬을 켠다.

- 사용자가 유튜브 **롱폼 원고/대본/스크립트** 작성을 요청할 때
- "이 주제로 영상 원고 써줘", "벤치마크 영상 두 개 줄 테니 원고 만들어줘" 류의 요청
- subtract-tube 파이프라인에서 주제·제목 단계 이후 원고 단계에 진입할 때

쇼츠(숏폼) 5블록 원고, 제목/썸네일만, 랜딩페이지는 이 스킬의 범위가 아니다(별도 스킬). 이 스킬은 **롱폼 본편 원고**만 만든다.

## 입력 (Inputs)

원고는 **상위 기준(채널 프로파일) + 두 종류의 소스(콘텐츠·구조)를 결합(짜집기)**해 만든다. v2에서 입력은 6종으로 확장된다.

- **(0) 채널 프로파일 — "누구 목소리로, 누구에게":** `yt-channel`(0단계)이 만든 **구독자 페르소나·니즈 / 말투·보이스 / 콘텐츠 방향성**. → **이것이 말투·구독자 니즈의 최상위 기준이다.** 아래 콘텐츠·구조를 아무리 차용해도, 최종 원고의 **어휘·문장 톤·호칭·니즈 타게팅은 반드시 이 프로파일에 맞춘다.** 그래야 원고가 남의 구조가 아니라 **내 보이스**로 나온다. (없으면 아래 표의 "채널 주제·타겟 시청자"로 1회 질문해 임시 프로파일을 세운다.)
- **(a) 콘텐츠 소스 — "무엇을 말할까":** `yt-radar`가 댄 **해외 현지화 대본/주제**. 영상에서 실제로 다룰 내용·정보·사례의 원천이다.
- **(b) 구조 템플릿 — "어떻게 보여줄까":** `yt-structure`가 **요소별 떡상 영상에서 따로 뽑은** `STRUCTURE TEMPLATE` 묶음. 이 스킬은 네 요소를 모두 소비한다 — **③ 제목/썸네일 구조(title_thumbnail)·④ 도입부 구조(intro)·⑤ 본문 구조(body=제목/썸네일 영상, 잠정)·⑥ CTA 구조(cta=제목/썸네일 영상, 잠정)**. 요소마다 `source`가 다를 수 있으며 본문·CTA는 제목/썸네일 영상을 잠정 재사용한다(추후 교체 가능). (구조 템플릿 입력이 없으면 아래 도입부 디벨롭의 벤치마크 차용 절차로 대체한다.)

이어서 아래를 수집한다. 빠진 항목은 "이 정보가 없으면 이렇게 처리한다"를 따른다.

| 입력 | 설명 | 없을 때 |
|---|---|---|
| **채널 프로파일 (yt-channel)** | 구독자 페르소나·니즈 / 말투·보이스 / 콘텐츠 방향성. **말투·구독자 니즈의 최상위 기준** | yt-channel 산출물 없으면 아래 "채널 주제·타겟 시청자"로 1회 질문해 임시 프로파일 구성 |
| 채널 주제·타겟 시청자 | 채널 방향성, 주 시청자 성별·연령 (채널 프로파일이 있으면 거기서 가져옴) | 사용자에게 1회 질문. 그래도 없으면 벤치마크 댓글의 작성자 성별·연령으로 추정 |
| **이번 영상 주제(핵심 문제 1문장)** | 시청자가 가진 단 하나의 문제를 1문장으로 | **필수.** 없으면 진행 불가 — 받아낼 것. 이게 결(結) 일치의 기준점 |
| 요소별 벤치마크(yt-structure) | 요소마다 다른 영상일 수 있음 — 제목/썸네일 영상 + 도입부 영상. 본문·CTA는 제목/썸네일 영상 잠정 재사용. 가급적 구독자 낮은데 고조회 | yt-structure 템플릿 없으면 제목+원문 스크립트 영상 1개라도 받아 아래 도입부 디벨롭 차용으로 대체. 0개면 "뷰트랩에서 같은 문제 영상 캡처/스크립트 확보 후 재요청" 안내 |
| 크리에이터 개인가치/자격 | 경력·이력·실적(35주차 개인가치 삽입용) | 없으면 개인가치 절을 "일반 권위 인용형"으로 대체하고 사용자에게 보강 권유 |
| CTA / 고정댓글 목적 | 구독 유도인지, 링크 클릭인지, 다음 영상 유도인지 | 기본값: "또 다른 문제제기 + 다음 영상 유도 + 고정댓글 확인 행동제시" |
| 분량 | 기본 **3000자** (±5%) | 미지정 시 3000자 |

추가로 가능하면 받는다: 벤치마크 영상의 **댓글 전체**(도입부·설득구조 강화용), 영상에서 쓰고 싶은 출처/사례.

## 방법론 (the core pipeline)

비즈니스PT 원고의 핵심은 "공감·정보 둘은 원고에서 반드시 확보, 재미·흥미는 편집에서 가미"다. 아래 순서대로 만든다.

### 0) 결(結) 일치 원칙 — 가장 먼저 고정

썸네일 · 제목 · 도입부 · 본문 · 고정댓글 · CTA가 **전부 동일한 문제(problem) 1개**를 다뤄야 한다. 결이 깨지면 클릭은 돼도 유지·전환이 안 된다.

작업 시작 시 **"핵심 문제 1문장"을 확정해 고정**하고, 이후 모든 구간(후킹·도입부·각 세그먼트·마무리·고정댓글)이 이 1문장을 향하도록 전파한다. 매 세그먼트 작성 시 "이 문장이 그 문제를 다루는가?"를 self-check.

### 1) 도입부 디벨롭 — 검증된 도입부를 1:1 단어 치환

도입부는 **도입부 유지율 60%**를 책임지는 구간이다. 신규 창작이 아니라 **검증된 벤치마크 도입부를 그대로 가져와 내 주제로 1:1 단어 치환**한다(구조 차용, 창작 아님).

구조 템플릿이 입력으로 들어온 경우, **`yt-structure`가 뽑은 `② intro` 구조(슬롯·hook_formula·intro_3elements·ties_to)를 인트로의 골격으로 삼고, 거기에 채워 넣을 콘텐츠는 `yt-radar`의 해외 현지화 대본에서 가져와 결합(짜집기)한다.** 도입부 구조는 제목/썸네일과 다른 영상에서 왔을 수 있으나(요소별 소싱), `ties_to`가 가리키는 `① title_thumbnail`의 문구를 첫 문장에서 그대로 재진술해 결(結)을 잇는다. 그리고 **완성된 도입부 문장은 채널 프로파일의 말투·호칭으로 다듬어 내 보이스로 나오게 한다.**

벤치마킹 범위를 점점 넓히는 **3단계**:

1. **1단계 — 같은 주제**: 같은 주제 영상의 도입부 차용 (예: 부동산 급매 → 부동산 급매)
2. **2단계 — 같은 분야·다른 주제**: 같은 분야 내 다른 주제 (예: 부동산 급매 → 부동산 임장)
3. **3단계 — 다른 분야·같은 공감포인트**: 분야는 달라도 공감 포인트가 같은 도입부 (예: 부동산 "급매로 싸게 잡는 법" 도입부 → 운동 "어깨 넓히는 법" 도입부로 1:1 치환)

치환 예시(교본): 부동산 도입부 "남들 다 비싸게 살 때 급매 하나로 수천만 원 아끼는 사람들이 있습니다" → 운동 주제로 단어만 갈아끼움 → "남들 다 헬스장만 다닐 때 이거 하나로 어깨 벌어진 사람들이 있습니다". **문장 골격은 그대로, 명사·동사만 내 주제로 교체.**

**도입부 3요소 (반드시 다 들어갈 것)**: ① 문제제기 ② 사례 ③ 유인(보상 or 약속).

### 2) 11유형 후킹 라이브러리 (34주차) — 도입부/전환멘트 유형 선택

실제 성공 영상으로 검증된 도입부·전환멘트 11개 유형. 주제·타겟에 맞는 1개(또는 조합)를 골라 후킹을 만든다.

| # | 유형 | 1줄 사용 가이드 | 예시 한 줄 |
|---|---|---|---|
| 1 | **큐레이션형** | 선택 피로가 큰 주제에서 "뭘 사야/해야 할지" 정리해준다 | "닭가슴살 뭐 먹지? 직접 다 먹어본 BEST 10" |
| 2 | **자격 + 나는 이렇게형** | 권위(연차/직업)를 앞세우고 내 방식을 공개 | "7년차 약사가 영양제 고르는 법" |
| 3 | **누구나 겪는 문제, 나도 겪었다형** | 보편적 문제 + 화자도 겪었다는 공감 | "다이어트 100번 실패한 저도 이건 됐습니다" |
| 4 | **비포/애프터형** | 변화 폭을 충격적으로 제시 | "외모 5배 떡상시키는 24가지 체크리스트" |
| 5 | **저평가 제품형** | 누구나 아는 브랜드를 이기는 숨은 것 | "다이슨보다 좋은데 아무도 모르는 이것" |
| 6 | **너는 이미 갖고 있어형** | 시청자가 이미 가진 것의 재발견 | "비싼 거 살 필요 없어요, 집에 다 있습니다" |
| 7 | **단점 보완형** | 모두가 인정하는 것의 약점을 보완 | "다들 좋다는 OO, 딱 하나가 아쉬웠는데 이걸로 해결" |
| 8 | **인지된 가격 할인형** | 가격이 각인된 제품을 싸게 | "10만 원짜리 그거, 이렇게 하면 3만 원" |
| 9 | **직접 같이 해보기형** | 화면에서 함께 시연 | "지금부터 저랑 같이 해보시죠" |
| 10 | **언더독형** | "나는 여러분보다 못한 사람이었다" | "운동 신경 0이던 제가 했으면 누구나 됩니다" |
| 11 | **갈아타기 간증형** | 갈아탐 → 극단적 효과의 희열 → 간증 | "OO 쓰다가 이걸로 바꿨더니, 진작 바꿀 걸 후회했습니다" |

**후킹 공식** (모든 유형에 적용): 사전신호(기대감 조성) → 예측오류 → 인지적 명료성.
> 예: "돈 많으면 다 부자인 줄 알았다(사전신호) / 진짜 부자를 만나보니(예측오류) / 진짜 부자는 다음 세대까지 자산을 유지시킨다는 걸 알았습니다(인지적 명료성)"

### 3) 본문 — 3000자 / 원고 6구성 / 문단 6논리

벤치마크 영상 2개의 원문 스크립트를 기반으로 **3000자 이내 유튜브 원고**를 짜고, 디벨롭한 도입부를 결합한다. **절대 요약하지 말고 원본과 동일한 분량(±5%)으로 세부 디테일까지 다 써라.**

**원고 6구성 (전체 흐름):**
1. 도입부 (후킹 + 도입부 3요소)
2. 정보
3. 개인가치 ① (35주차 삽입)
4. 개인가치 ② / 결론
5. 추천
6. 기대감 (마무리 → 키콘텐츠/다음 영상 유도)

**문단 논리구조 6요소 (각 정보 문단 내부):**
주장 → 근거 → 원리/기원 → 예시 → 반론 → 대안

### 4) 개인가치 삽입 (35주차)

검증된 콘텐츠 구조에 **크리에이터의 자격·이력을 1절(한 줄)로 끼워넣어** 차별화한다. 표현은 그대로 두고 권위만 주입한다.
> 예시: "당신의 체력을 비약적으로 상승시키는 3가지 방법" → 개인가치(K리그 311경기) 주입 → **"10년간 311경기를 뛴 제가 증명한, 평범한 몸이 미친 체력으로 바뀌는 3가지 방법"**

개인가치 자격이 입력에 없으면 이 자리를 "일반 권위 인용"(전문가·기관·통계)으로 대체하고, 사용자에게 본인 자격 보강을 권한다.

### 5) 신뢰도 보강 6작업

각 보강은 "공감↑ 또는 신뢰도↑인가?"를 기준으로 삽입한다.
1. 원리/주의점 삽입
2. 실제로 해보고 구체적 과정 보여주기 (화면큐로 처리)
3. 원본 영상 캡처 (화면큐로 처리)
4. 국내 사례로 치환
5. 반론 근거 미리 넣기 (예상 문제점/의문점 선제 반박 — 예: "OO 하지 마세요", "보험은 대면이어야 하는 거 아냐? → 본질은 신뢰")
6. 전문가 인터뷰 추가(인용)

### 6) 출처 명시 규칙 (의무)

본문(도입부와 본론 사이)에 **참고 채널/영상 출처 문장**을 반드시 삽입한다.
> 템플릿: "오늘 알려드릴 정보는요, 현재 국내에서 **[N]만뷰 이상** 나온 **[주제]** 중에서도 **[전문가/직업]**의 실전 노하우입니다. 해당 내용은 **[채널A], [채널B]** 채널의 콘텐츠를 참고했습니다."

### 7) 댓글 마이닝

벤치마크 영상 댓글이 있으면:
- **공감 댓글** → 도입부 공감 포인트 강화 (도입부 디벨롭 원료)
- **망설임/반론 댓글** → 본문 설득구조·반론 선제 블록 보강

댓글이 있으면 작성자 성별·연령을 분석해 타겟 니즈에 맞는 톤을 잡는다.

### 8) 마무리 + 고정댓글

- **마무리**: 또 다른 문제제기/기대감으로 다음(키)콘텐츠 유도.
- **고정댓글**: 행동제시. 증거자료형 또는 휘발성형 템플릿 사용.
  - 증거자료형: "(성과 낸 사람들)이 실제로 (결과) 낸 방법 그대로만 하면 여러분도 (목표) 얻습니다. 고정댓글 (링크) 클릭하면 (실행방법/사례) 볼 수 있어요. 영상 끝나면 바로 고정댓글 확인하세요."

## 품질 게이트 (Quality Gates)

원고를 내보내기 전 자동 점검한다. 하나라도 실패하면 고쳐서 다시 통과시킨다.

- [ ] **공감 + 정보** 둘 다 확보했는가? (재미·흥미는 편집 몫이지만 공감·정보는 원고 의무)
- [ ] **분량 3000자 ±5%**인가? — **절대 요약하지 말 것.** 짧으면 디테일을 더 써서 분량 유지
- [ ] **결(結) 일치**: 후킹·도입부·본문·마무리·고정댓글·CTA가 전부 핵심 문제 1문장을 다루는가?
- [ ] **출처 명시** 문장이 본문에 들어갔는가?
- [ ] **CTA 결 일치**: 고정댓글/행동제시가 같은 문제를 향하는가?
- [ ] **도입부 3요소**(문제제기·사례·유인) 모두 있는가?
- [ ] **개인가치** 1절이 삽입됐는가? (없으면 일반 권위로 대체했는가?)
- [ ] 목표 KPI를 의식했는가? — **클릭률 10%+ / 도입부 유지 60%+ / 평균 시청 4분+ / 조회수 1000+**

## 출력 계약 (Output Contract) — 페이스리스 핵심

원고를 **세그먼트로 분할**해 출력한다. 각 세그먼트는 두 블록을 가진다. 이렇게 해야 다음 스킬 `yt-voiceover`(TTS)와 `yt-render`(Remotion 조립)가 그대로 소비할 수 있다.

```
## 세그먼트 N
[나레이션]
(TTS로 읽힐 순수 대사만. 지시문·괄호 설명 금지. 한 문단.)

[화면/비주얼 큐]
- 자막 키워드: (강조할 단어/숫자)
- B-roll / 이미지: (보여줄 화면 지시 — 원본 캡처/국내 사례/시연 등)
- 강조: (확대·하이라이트·전환 포인트)
```

규칙:
- `[나레이션]`은 **TTS가 그대로 읽을 수 있는 순수 한국어 대사**만. 무대 지시·괄호 설명을 섞지 않는다.
- `[화면/비주얼 큐]`에 신뢰도 보강 중 "시연·원본캡처"를 화면 지시로 흡수한다.
- 세그먼트 길이는 한 호흡(대략 2~5문장)으로 끊어 TTS·자막 동기화가 쉽게 한다.

원고 **맨 끝**에 아래 3종을 함께 출력한다.
- **제목 후보 3개** (결 일치, 세일즈 키워드 앞쪽)
- **설명란 초안** (해시태그 5개를 맨 앞에, 메인키워드 3회+)
- **고정댓글 초안** (행동제시, 증거자료형/휘발성형 중 택1)

## Worked Example (간결)

**핵심 문제 1문장**: "헬스장 다녀도 어깨가 안 벌어진다."
**벤치마크**: ① 부동산 "급매로 수천만 원 아끼는 법"(12만뷰) ② 운동 "어깨 운동 루틴"(8만뷰)

**도입부 디벨롭 (3단계 차용 → 1:1 치환)**
- 차용 원문(부동산): "남들 다 비싸게 살 때, 급매 하나로 수천만 원 아끼는 사람들이 있습니다."
- 치환 도입부(어깨): "남들 다 헬스장만 다닐 때, 이것 하나로 어깨가 벌어진 사람들이 있습니다." (후킹 유형 10 언더독 + 후킹 공식 적용)

**세그먼트 1**
```
[나레이션]
남들 다 헬스장만 다닐 때, 이것 하나로 어깨가 벌어진 사람들이 있습니다. 저도 운동 신경 제로였습니다. 그런데 딱 한 가지를 바꾸고 나서, 3개월 만에 어깨 너비가 달라졌습니다.
[화면/비주얼 큐]
- 자막 키워드: 이것 하나 / 3개월 / 어깨 너비
- B-roll: 좁은 어깨 → 넓은 어깨 비포애프터 이미지
- 강조: "3개월" 숫자 확대
```

**세그먼트 2**
```
[나레이션]
오늘 알려드릴 내용은, 국내 8만뷰 이상 나온 어깨 운동 콘텐츠 중에서도 실제 효과가 검증된 핵심만 모은 겁니다. 트레이너 채널 두 곳의 내용을 참고했습니다. 핵심은 무게가 아니라 '각도'입니다.
[화면/비주얼 큐]
- 자막 키워드: 8만뷰 검증 / 무게가 아니라 각도
- B-roll: 참고 채널 화면 캡처(출처 표기)
- 강조: "각도" 하이라이트
```

**고정댓글 초안**
"어깨 벌어진 분들이 실제로 한 그 루틴, 고정댓글 링크에 정리해뒀습니다. 영상 끝나면 바로 확인하고 오늘부터 따라 해보세요."

---

> 이 스킬은 비즈니스PT 방법론에 충실해야 한다. "좋은 원고 쓰기" 같은 일반 조언으로 대체하지 말 것. 모든 산출물은 결 일치·차용 치환·세그먼트 출력 규칙을 지킨다.
