# yt-channel — 내 채널 학습 → 재사용 "채널 프로파일" 빌더 (0단계)

> 호출자: 빼기연구소 크리에이터(파이프라인 최초 1회 + 월 1회 재학습) 또는 subtract-tube 오케스트레이터의 0단계.
> 다운스트림 소비자: **거의 모든 스킬.** 특히 `yt-script`(내 말투·구독자 니즈로 원고 생성), `yt-radar`(해외 주제를 내 구독자 니즈로 현지화), `yt-structure`/`yt-title`(내 컨셉·타겟에 맞는 구조·제목 선택).
> 목적: **"누구에게(구독자) / 어떤 목소리로(말투) / 무슨 결로(방향성) 말하는 채널인가"를 한 번 정밀하게 학습**해 재사용 자산으로 박제한다. 매 영상마다 톤·타겟을 새로 추측하지 않게 만드는 최상위 입력이다.
> 위치: 프로세스 v2의 **0단계(내 채널 분석/학습)**. 1~10단계(주제·구조·원고·렌더·분석)는 모두 이 프로파일을 전제로 돈다.
> 개념적 자매 스킬: ECC `brand-voice`(소스 자료에서 보이스 프로파일을 1회 추출해 반복 재사용). 이 스킬은 그 패턴을 **유튜브 채널 + 구독자 니즈 + 콘텐츠 방향성**까지 확장한 것이다.

---

## When to Activate

다음 중 하나면 이 스킬을 켠다.

- subtract-tube 파이프라인을 **처음 세팅**할 때(0단계 — 다른 무엇보다 먼저).
- 사용자가 "내 채널 분석해줘", "채널 프로파일 만들어줘/갱신해줘", "내 말투·구독자 학습해줘"라고 할 때.
- **월 1회 재학습** 트리거(신규 영상·댓글·구독자 변동 반영).
- 다운스트림 스킬이 `CHANNEL PROFILE`을 요구하는데 **아직 없거나 1개월 이상 묵었을 때**.

이 스킬은 **'내' 채널**만 다룬다. 해외 트렌드 주제 소싱은 `yt-radar`, 국내 떡상 구조 추출은 `yt-structure`의 몫이다. 여긴 "나는 누구이고 누구에게 말하는가"만 정의한다.

## 입력 / 데이터 수집 (Collection)

> ⚠️ **API 키 필요.** 내 영상 목록·통계·댓글을 긁으려면 **YouTube Data API v3 키**(또는 OAuth)가 필요하다. 키가 없으면 아래 "수동 export 폴백"으로 진행한다.

### 1) 자동 수집 — YouTube Data API v3 (권장)

사용자에게 **API 키**(또는 본인 채널 권한 OAuth 토큰)와 **채널 ID/핸들**을 받는다. 키는 환경변수/시크릿으로만 받고 코드·로그에 하드코딩하지 않는다.

| 수집물 | API / 출처 | 학습에 쓰는 곳 |
|---|---|---|
| 내 영상 목록 + 메타 | `search.list`(channelId) → `videos.list` | 방향성·컨셉(이어온 주제 라인) |
| 영상별 조회/시청 지표 | `videos.list(part=statistics)` (+ 가능하면 YouTube **Analytics API**의 평균시청·유지율) | 어떤 주제가 먹혔나 → 구독자 니즈 신호 |
| 댓글 | `commentThreads.list`(videoId/allThreadsRelatedToChannelId) | 구독자 페르소나·니즈(언어·반복 질문·불만·연령단서) |
| 영상 대본/자막 | `youtube-transcript-api`(Python) 또는 `yt-dlp --write-auto-sub --skip-download` | **말투·보이스**(어미·호흡·반복어) |
| 채널 소개·재생목록 | `channels.list(part=snippet,brandingSettings)` · `playlists.list` | 방향성·컨셉(채널이 자기를 뭐라 정의하나) |

> 표본은 **최근 영상 우선 + 성과 상위 영상**을 섞어 10~30개. 너무 오래된 영상은 톤이 다를 수 있으니 사용자가 "이게 더 정본"이라 하지 않는 한 최신을 우선한다(brand-voice의 source priority와 동일 원칙).

### 2) 수동 export 폴백 (API 키 없을 때)

키가 없거나 할당량이 막히면 사람이 넣어준다.

- **YouTube Studio → 콘텐츠/분석 → 내보내기(CSV)**: 영상 목록·조회수·평균 시청 지속 시간·구독자 증감.
- 대표 영상 **3~5개의 대본**(직접 붙여넣기 or 자막 파일).
- 대표 영상의 **댓글 캡처/복붙**(상위 + 최신 섞어 수십 개).
- 채널 소개글·대표 재생목록 제목.

이 경우 출력 프로파일 `meta.source`에 `manual-export`로 표시하고, 표본이 얇으면 신뢰도 경고를 단다.

## 학습 3축 (the core analysis)

수집물을 아래 **3축**으로 환원한다. 각 축은 `CHANNEL PROFILE`의 한 블록이 된다.

### ① 구독자·시청자 페르소나 + 니즈 — *가장 중요*

> v2 0단계 핵심: **"구독자 니즈 파악이 핵심."** 누구에게 말하는지 모르면 결(結)을 맞출 수 없다.

- **댓글 텍스트 분석:** 자주 나오는 질문·불만·요청·감탄을 군집화. "이거 어떻게 해요?", "저도 ~인데", "~가 안 돼요" 패턴 = 미충족 니즈.
- **시청 패턴 분석:** 어떤 주제·길이 영상에서 평균 시청·유지율이 높은가 → 구독자가 실제로 끝까지 본 주제 = 진짜 니즈.
- **인구 단서 추정:** 댓글 작성자 말투·관심사·언급(직장/육아/나이대 단서)로 성별·연령대를 추정(단정 금지, 신뢰도 표기).
- 산출: **페르소나 1~2명**(누구·상황·고민) + **니즈 Top 5**(시청자가 가진 문제 1문장 리스트).

### ② 말투·보이스 — *원고가 그대로 빌릴 자산*

> 대본/자막에서 추출. brand-voice의 "What to Extract"를 유튜브 나레이션에 맞춰 적용.

- **어미·종결 습관**(예: "~거든요", "~인 거죠", "~해보세요" 빈도).
- **호흡/문장 길이**(짧게 끊나, 길게 가나) · 도입 멘트 습관.
- **반복어·입버릇(verbal tics)**(자주 쓰는 접속·강조어, 시그니처 표현).
- **호칭**(여러분/구독자님/형·누나 등) · 존댓말/반말 결.
- **금지어·안 하는 것(bans):** 이 채널이 절대 안 쓰는 말투·클리셰(직역체, 오글거리는 인사 등). 사용자가 싫어하는 표현을 명시적으로 받아 박제.
- 산출: **리듬 / 입버릇 / 금지어** 3종 + 짧은 **예문 2~3개**(다운스트림이 톤 매칭에 쓸 샘플).

### ③ 콘텐츠 방향성·컨셉 — *주제 선택의 가드레일*

- 채널 소개·재생목록·성과 상위 영상에서 **이어온 주제 라인**(이 채널이 다루는/안 다루는 영역).
- **컨셉 한 문장**(이 채널은 결국 무엇을 약속하나 — 예: "AI 자동화로 1인 사업 비용 빼기").
- **세부 토픽 클러스터**(반복 등장 주제 3~6개).
- 산출: **themes(주제 라인) + concept(한 문장) + off-limits(다루지 않는 영역)**.

## 출력 계약 (Output Contract)

재사용 가능한 `CHANNEL PROFILE` 블록을 산출한다. 다운스트림 스킬이 **세션 컨텍스트에 그대로 붙여 소비**할 수 있도록 구조적·간결하게. (문학 비평이 아니라 **운영 재사용**이 목적 — brand-voice 원칙.)

저장 위치: `subtract-tube/config/channel-profile.md` (재사용 자산, 1개 유지·덮어쓰기 갱신).

```
# CHANNEL PROFILE — {채널명}
meta:
  channel: {채널명 / @핸들}
  source: api | manual-export
  sampled: {영상 N개 · 댓글 M개 · 대본 K개}
  built_at: {YYYY-MM-DD}
  next_review: {YYYY-MM-DD (+1개월)}
  confidence: high | medium | low   # 표본 얇으면 low + 경고

audience:                 # 축①
  persona:
    - { name, 상황, 핵심 고민 }     # 1~2명
  needs:                  # 시청자가 가진 문제 1문장 Top5 (yt-script '핵심 문제'의 후보 풀)
    - "..."
  demographic_guess: { 성별, 연령대, 신뢰도 }   # 추정임을 명시

voice:                    # 축②
  rhythm: "문장 길이·호흡 한 줄 요약"
  tics: ["자주 쓰는 어미/입버릇/시그니처 표현"]
  honorific: "호칭·존댓말 결"
  bans: ["이 채널이 절대 안 쓰는 표현/클리셰"]
  samples: ["내 톤이 살아있는 실제 대본 한 줄", "..."]

direction:                # 축③
  concept: "채널 한 문장 약속"
  themes: ["반복 주제 클러스터 3~6"]
  off_limits: ["다루지 않는 영역"]
```

### 다운스트림 소비 가이드 (이 프로파일을 어떻게 쓰나)

| 소비 스킬 | 무엇을 가져가나 |
|---|---|
| **yt-script** | `voice`(tics·rhythm·bans)로 나레이션 톤을 내 말투에 고정 · `audience.needs`에서 "핵심 문제 1문장"을 끌어와 결(結) 기준점으로 · `audience.persona`로 공감 구간 작성 |
| **yt-radar** | `audience.needs`·`direction.themes`로 해외 주제 중 **내 구독자에게 통할 것**만 우선 현지화 · `off_limits`는 큐에서 배제 |
| **yt-structure / yt-title** | `audience.demographic_guess`·`direction.concept`에 맞는 구조·제목 톤 선택 |

> 규칙: 다운스트림은 **프로파일을 추측으로 덮어쓰지 않는다.** 충돌하면 최신 `CHANNEL PROFILE`이 우선. 프로파일이 `confidence: low`면 그 스킬은 사용자에게 1회 확인을 권한다.

---

## 갱신 (Refresh)

- **월 1회 재학습 권장.** 신규 영상·댓글·구독자 변동을 반영해 `audience.needs`·`voice.samples`를 업데이트한다.
- 채널 방향을 크게 튼 경우(새 시리즈·타겟 변경) 즉시 재학습.
- 갱신 시 `built_at`/`next_review`를 새로 찍고, 직전 프로파일과 **달라진 점 3줄 요약**을 남겨 다운스트림이 변화를 인지하게 한다.

## 자동 vs 수동 경계

| 단계 | 분류 | 사람이 할 일 |
|---|---|---|
| API/Export로 데이터 수집 | ✅ 자동(키 있을 때) | API 키·채널ID 1회 제공 / 키 없으면 CSV·대본 export |
| 3축 학습(페르소나·말투·방향성) | ✅ 자동 분석 | 없음 |
| 인구통계·니즈 **확정** | 🙋 반자동 | 추정이 어긋나면 사람이 정정(특히 `confidence: low`) |
| 금지어(bans) 지정 | 🙋 수동 | 사용자가 싫어하는 표현을 1회 명시 |
| 프로파일 채택·갱신 | 🙋 수동 | 월 1회 재학습 트리거·검수 |

> 인구통계·니즈는 **추정**이다. 단정하지 말고 신뢰도와 함께 내고, 사람이 확정하게 둔다.

## 품질 게이트 (Quality Gates)

프로파일을 저장하기 전 점검한다.

- [ ] 3축(audience / voice / direction)이 **모두** 채워졌는가?
- [ ] `audience.needs`가 **yt-script가 바로 쓸 1문장**들인가? (모호한 키워드 나열 금지)
- [ ] `voice.bans`(금지어)와 `voice.samples`(실제 톤 예문)가 들어갔는가?
- [ ] 표본이 얇으면 `confidence: low` + 경고를 달았는가?
- [ ] `meta.source`(api/manual)와 `next_review`(+1개월)를 찍었는가?
- [ ] API 키를 **출력·로그·저장 파일에 노출하지 않았는가?** (시크릿 보호)

## Worked Example (간결)

**채널**: 나는빼기연구소 (@nanun-bppgi) · source: api · sampled: 영상 22 / 댓글 410 / 대본 6

```
# CHANNEL PROFILE — 나는빼기연구소
meta: { channel: "@nanun-bppgi", source: api, sampled: "영상22·댓글410·대본6",
        built_at: 2026-06-23, next_review: 2026-07-23, confidence: medium }

audience:
  persona:
    - { name: "1인 자영업자 김대표", 상황: "혼자 다 함", 핵심 고민: "사람 안 늘리고 일을 줄이고 싶다" }
  needs:
    - "외주·직원에 매달 나가는 돈을 자동화로 빼고 싶다"
    - "AI 쓴다는데 막상 뭐부터 붙여야 할지 모르겠다"
    - "툴은 많은데 내 일에 진짜 쓸 건 뭔지 모르겠다"
  demographic_guess: { 성별: "남성 다수", 연령대: "30~40대", 신뢰도: medium }

voice:
  rhythm: "짧게 끊고 핵심 먼저. 숫자·비용으로 못 박음"
  tics: ["~거든요", "결론부터 말하면", "이거 하나면 됩니다", "빼기"]
  honorific: "존댓말 + 시청자 '여러분'"
  bans: ["여러분 안녕하세요~ 류 직역체 인사", "오글거리는 감성 멘트", "근거 없는 단정"]
  samples: ["결론부터 말하면, 이 일은 사람이 안 해도 됩니다.",
            "한 달에 200 나가던 걸, 이거 하나로 0으로 뺐습니다."]

direction:
  concept: "AI 자동화로 1인 사업의 '비용·노동'을 빼는 채널"
  themes: ["n8n 자동화", "AI 에이전트", "외주 비용 절감", "노코드 툴"]
  off_limits: ["투자·코인 수익 인증", "정치"]
```

**다운스트림 효과**: yt-radar는 해외 "AI 에이전트" 영상을 `needs[1]`("뭐부터 붙일지 모르겠다")로 현지화하고, yt-script는 도입부를 `voice.samples` 톤("결론부터 말하면…")으로 쓰며 `bans`의 직역체 인사를 자동 배제한다.

> 이 스킬은 **재사용 자산을 만드는 0단계**다. 1회용 분석으로 끝내지 말고 `channel-profile.md`로 박제해 모든 다운스트림이 같은 "나"를 공유하게 한다. 추측은 신뢰도와 함께 내고, 확정은 사람이 한다.
